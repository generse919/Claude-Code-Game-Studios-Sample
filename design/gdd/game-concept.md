# Game Concept: CLASH

*Created: 2026-04-15*
*Status: Draft*

---

## Elevator Pitch

> 横視点の1v1格闘ゲーム。間合いの攻防と読み合いが全ての勝敗を決める。
> コンボを極めれば強くなれるが、追い詰められた時こそパリィが最大の逆転劇を生む。
> プリミティブ3Dモデルのシンプルな外観の奥に、深い心理戦が待っている。

## Core Fantasy

「俺はお前の全てを見切った」——相手の行動を読み切り、絶妙なタイミングのパリィで
完璧なカウンターを決める瞬間の万能感。

崖っぷちの状況から、たった1回の正確な読みで試合をひっくり返す。
その逆転劇の主人公になれるゲーム。

コンボが決まる気持ちよさ、間合いのぎりぎりを制する緊張感、そして読み勝った瞬間の
爆発的なカタルシス——これが CLASH の約束する体験。

---

## Unique Hook

「ストリートファイターのような格闘ゲーム、**AND ALSO** 読み勝ちへのご褒美として
パリィが逆転劇を生む——間合い管理と心理戦が全ての勝敗を決める」

パリィは防御技ではなく、**逆転の切り札**として設計する。
追い詰められた状況でこそ最大のリターンをもたらし、諦めない戦い方を可能にする。

## Visual Identity Anchor

**Direction: Brutalist Clarity（機能美）**

プリミティブジオメトリ（キューブ・カプセル・シリンダー）だけで構成される世界。
これは妥協ではなく、美学として選んだ選択。

| 視覚原則 | 内容 | 設計テスト |
| ---- | ---- | ---- |
| **情報の明確さ** | 距離・攻撃範囲・体力は常に視覚的に読み取れる | HUDなしでも「危険な距離」が分かるか？ |
| **特別な瞬間の強調** | パリィ成功時だけ派手なエフェクト——その瞬間を際立たせる | 通常攻撃とパリィ成功の視覚的差異は明確か？ |
| **ステージの引き算** | 背景もプリミティブで統一。キャラクターの動きだけが目立つ | ステージにキャラクターが埋もれていないか？ |

**カラー哲学**: キャラクターはカラーコーディングで区別（例: プレイヤー1=青、プレイヤー2=赤）。
攻撃エフェクトは黄〜白のアクセントカラー。パリィ成功時は全画面フラッシュ的な輝きを使用。

## Player Experience Analysis (MDA Framework)

### Target Aesthetics (What the player FEELS)

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Sensation** (sensory pleasure) | 1 | パリィ成功時の爽快感、打撃の手応え、間合いぎりぎりの緊張感 |
| **Challenge** (obstacle course, mastery) | 2 | コマンド技・コンボの習得曲線、読み合いの深度 |
| **Fellowship** (social connection) | 3 | ローカル対戦での直接的な駆け引きと共有体験 |
| **Discovery** (exploration, secrets) | 4 | コンボルートの発見、キャラクターの強み・弱みの理解 |
| **Expression** (self-expression, creativity) | 5 | 自分なりの戦闘スタイル（攻め型・カウンター型） |
| **Fantasy** (make-believe) | N/A | — |
| **Narrative** (drama, story arc) | N/A | — |
| **Submission** (relaxation) | N/A | — |

### Key Dynamics (Emergent player behaviors)

- プレイヤーは相手の行動パターンを記憶しようとする（「あいつはピンチになるとパリィを狙う」）
- パリィ成功率が上がるにつれてより大胆な攻めが可能になる
- コマンド技を「温存するか今使うか」という択が自然に発生する
- 間合いの内外で技の強弱が逆転する体験から、距離管理を意識するようになる

### Core Mechanics (Systems we build)

1. **間合い管理** — 距離によって技のリーチ・優先度・硬直が変わる。キャラクター間の相対距離が全ての攻防の文脈を決定する
2. **パリィシステム** — ガード入力のタイミングで攻撃を弾き、カウンター状態（無敵 + 反撃チャンス）を生む。タイミングが早すぎ・遅すぎると通常ガードになる
3. **基本攻撃体系** — 軽パンチ・重パンチ・軽キック・重キック。リーチ・ダメージ・硬直のトレードオフ
4. **コマンド必殺技** — シーケンス入力（例: ↓→P）で出せる高リターン技。ヒット時の見返りが大きい分、ガードされると大きな隙を生む
5. **ラウンド制勝敗判定** — 体力を0にして2ラウンド先取で勝利。45〜60秒のラウンドタイマー（時間切れは体力有利側の勝利）

## Player Motivation Profile

### Primary Psychological Needs Served

| Need | How This Game Satisfies It | Strength |
| ---- | ---- | ---- |
| **Autonomy** (freedom, meaningful choice) | いつ攻めるか、パリィを狙うか、コマンド技を温存するかの戦略的判断 | Supporting |
| **Competence** (mastery, skill growth) | コンボ精度・パリィタイミング・読み合いの上達が直接勝率に反映される | **Core** |
| **Relatedness** (connection, belonging) | 同じ画面を見ながら戦う対面対戦のリアルな感情的やり取り | Supporting |

### Player Type Appeal (Bartle Taxonomy)

- [x] **Achievers** — コンボルートの完全習得、パリィ成功率の向上、連勝記録
- [ ] **Explorers** — コンボルートの発見、各キャラの強み・弱みの理解（限定的）
- [ ] **Socializers** — ローカル対戦での感情共有（限定的）
- [x] **Killers/Competitors** — 1v1の直接対決。勝敗が即座に明確になる設計

### Flow State Design

- **Onboarding curve**: 初回プレイ3分以内に移動・パンチ・キック・パリィを全て試せる操作設計。チュートリアルなしでも触れる
- **Difficulty scaling**: 基本操作はシンプル（ボタン1つで攻撃）。コマンド技・コンボ精度・読み合いが上達の無限の奥行きを作る
- **Feedback clarity**: パリィ成功時の専用エフェクト・音響で「うまくいった」が即座に分かる。ダメージ量もヒットストップで体感できる
- **Recovery from failure**: 1ラウンド負けても即次ラウンド開始。試合負けも次の試合まで数秒。失敗から学んで修正する間が短い

## Core Loop

### Moment-to-Moment (30秒)

**間合いの攻防**。前進・後退・牽制攻撃で距離を制する。
相手が動いた瞬間に攻撃か・パリィ狙いか・コマンド技か——3択の心理戦。
読み勝てばパリィカウンターまたは大技がヒット。読み負ければ体力を削られる。

この攻防の繰り返しが30秒ループ。純粋な判断と反射と読みの交錯。

### Short-Term (5〜15分)

- **ラウンド内**: 体力を削り合い、残り体力に応じてリスク許容度が変わる
- **ラウンド間**: 「さっきの負け方の原因」を修正して次ラウンドへ
- **試合**: 2ラウンド先取で勝負決定。負けた方は「もう1試合」の衝動が生まれる

### Session-Level (30〜60分)

複数試合を重ねて相手の癖を覚え、対策が深まる。
「あいつはガード多いからコマンド技が刺さる」という学習が積み重なる。
自然な停止点は試合の区切り。次に起動したくなる理由は「あの読み合いをもう一度」。

### Long-Term Progression

コンテンツ解放ではなく**スキル習得**が唯一の進行。
- コンボ精度の向上（ミスなく繋げられるようになる）
- パリィタイミングの習得（どんな攻撃でも弾けるようになる）
- 読み合いの深度（相手の癖を読んで先手を打てるようになる）

「強くなったのに負ける」体験が次の探求を生む。

### Retention Hooks

- **Mastery**: コンボ精度・パリィ成功率・読み合いの上達。上達の余地が常にある
- **Curiosity**: 「あのコマンドを決めたら試合どう変わるか」「この間合いで別の択は？」
- **Social**: 隣の人に「もう1試合」と言いたくなる対面対戦の引力

## Game Pillars

### Pillar 1: 「間合いが全て」
全ての行動は距離によって意味が変わる。攻撃・防御・必殺技は常に間合いのコンテキストで評価される。

*Design test*: 新しい技を追加する時「これは間合い管理に新しい選択肢を与えるか？」と問う。YESでなければ不要。

### Pillar 2: 「読み勝ちへの報酬」
相手の行動を正しく読んだ瞬間、明確で気持ちいいフィードバックが返ってくる。パリィ成功は最高の報酬。

*Design test*: パリィ成功後に「やった！」という瞬間があるか？音・エフェクト・ヒット感が揃っているか？

### Pillar 3: 「逆転可能な緊張感」
劣勢でも諦めない設計。ピンチであるほどパリィのリターンが輝く瞬間がある。

*Design test*: 「もうダメだ」と感じる状況から逆転できる経路が設計上常に存在するか？

### Pillar 4: 「単純な外観、深い読み合い」
プリミティブなグラフィック、直感的な操作体系。でも上達するほど奥が見える。

*Design test*: 初回プレイ3分以内にパンチ・キック・パリィを全て試せるか？ベテランが1時間後も新しい発見があるか？

### Anti-Pillars (What This Game Is NOT)

- **NOT コンテンツボリューム**: RPG的な解放要素・キャラクター収集は作らない。ピラー「間合いが全て」を薄め、ゲームジャムスコープを破壊する
- **NOT 救済オートコンボ**: 初心者向けの自動コンボ補助は入れない。ピラー「読み勝ちへの報酬」を損なう——習得の達成感が失われる
- **NOT グラフィックリアリティ**: プリミティブモデルは美学。高品質アセットへの迷いはスコープを破壊し、ビジュアルアイデンティティを失わせる
- **NOT コンテンツ格差**: 解放要素で強キャラが増える設計はしない。逆転の物語は平等な条件からしか生まれない

## Risks and Open Questions

### Design Risks

- パリィウィンドウの調整が難しい——シビアすぎると「使えない技」、広すぎると「全部パリィできる」になりバランスが崩れる
- ゲームジャムのローカル対戦のみという制約で、1人で体験できないデモになる可能性（AIの有無を要検討）
- 2キャラクターのみでは対戦の多様性が薄い。「もう1キャラ見たい」で終わる可能性

### Technical Risks

- UE5 のフレームパーフェクトな当たり判定実装——格闘ゲームに必要なフレーム精度とUE5のデフォルト設定の乖離
- コマンド入力シーケンス検出（↓→P等）がEnhanced Input Systemの標準機能にないため自作が必要
- UE5 プロジェクト初期設定・シェーダーコンパイルがゲームジャム序盤の時間を消費する

### Market Risks

- 格闘ゲームの固定ファン以外への訴求が難しい——ジャンルの参入障壁
- ゲームジャムはオンライン公開が主流だが、ローカル対戦のみではitch.io等でのデモとして弱い

### Scope Risks

- コマンド入力（MVPに含めるか、ボタン1押し必殺技に簡略化するか）の判断が未確定
- パリィのバランス調整は試作なしに決められず、反復テストの時間が必要

### Open Questions

- パリィの受付フレームは何フレームが最適か？→ プロトタイプで3〜8フレームの範囲を試す
- MVPでコマンド入力は必要か？→ まずボタン1押し必殺技でコアループを検証し、後で追加する方針を推奨
- 1人プレイ用AIは必要か？→ ゲームジャム公開形式によって判断（オンライン公開なら優先度高）

## MVP Definition

**Core hypothesis**: 「間合い管理とパリィを組み合わせた格闘の読み合いは、2人で対戦した時に楽しいか？」

**Required for MVP**:

1. プリミティブ3Dキャラクター2体（移動・ジャンプ・しゃがみ）
2. 基本攻撃（軽パンチ・重パンチ・軽キック・重キック）+ 1ボタン必殺技1種/体
3. パリィシステム（ガード入力のタイミング判定、成功時のエフェクト・カウンター状態）
4. 体力システム + 2ラウンド先取の勝敗判定 + ラウンドタイマー（45〜60秒）
5. ローカル2人対戦（キーボード分割 or コントローラー対応）

**Explicitly NOT in MVP**:

- コマンド入力必殺技（↓→P等のシーケンス）→ ボタン1押しで代替
- キャラクター選択画面
- BGM（効果音のみで可）
- ステージバリエーション
- CPU対戦（AIの実装）

### Scope Tiers

| Tier | Content | Features | Timeline |
| ---- | ---- | ---- | ---- |
| **MVP** | キャラ2体、ステージ1 | 基本攻撃、パリィ、1ボタン必殺技、体力・ラウンド判定、ローカル2P | 2週間 |
| **Vertical Slice** | キャラ2体、ステージ1 | MVP + コマンド入力必殺技1〜2種/体 + SE + 簡易キャラ選択 | 3〜4週間 |
| **Alpha** | キャラ2〜3体、ステージ1〜2 | 全機能（粗削り）+ BGM | 5〜6週間 |
| **Full Vision** | キャラ4体、ステージ3 | 全機能ポリッシュ + CPU対戦 | 6〜8週間、ソロ開発 |
